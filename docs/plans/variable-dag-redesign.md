## ⚠️ 做 demo 时踩到的坑（**这些是重来的成本，务必先读**）

我在 `/tmp` 做了个可跑的示例页验证形态，踩了这些坑。每一条都是引擎里已经解决/有先例的，但不知道就会重踩：

### 1. KaTeX 不吃注入的 HTML —— 锚点恒为 0

想给公式里的变量加高亮，**不能**把 `<span>` 拼进 LaTeX 字符串：KaTeX 把它当文本丢掉。实测锚点数恒为 0。

**正解**：`\htmlId{id}{...}` / `\htmlClass{cls}{...}`，让 KaTeX 自己生成带属性的元素。**且必须配 `trust: true`** —— 不加时 KaTeX **静默**不生成元素（引擎 `formula.js` 的 `katexOpts` 注释专门写了这条）。

### 2. `\region{...}` 的 body 里嵌套 `\slot{}` —— 正则展开必炸

`\region{CORR}{\exp(\slot{MOLD} - \slot{MNEW})}` 的 body 里有 slot，**不递归**就会把字面量 `\slot`/`\regionCORR` 交给 KaTeX，屏幕上打出来。

**正解**：逐字符扫描 + 花括号配对 + 递归（引擎 `formula.js` 的 `expand()` 就是这么写的）。正则处理不了嵌套。

### 3. 公式的值必须**逐 slot 单独渲染**，不能改 textContent

触发替换的**恰恰是符号档**（`\slot{BLKMAX}` → `\max_i x^{(j)}_i`），那本身是 LaTeX，`textContent` 会把反斜杠打到屏幕上。引擎的文件头用了整整两段讲这个坑。

### 4. 分层算法会**跳号** —— 按层号算尺寸会得出荒诞结果

`layer[w] = max(layer[w], base+1)` 累积会产出 `0, 1, 17, 18, 19` 这种层号。按层号直接算画布宽度得到 **4526px**，图被压成一条线。

**正解**：按「实际出现过的层」重编号，再用重编号后的序号算尺寸。

### 5. 横排还是竖排，要按**离目标比例的距离**选，不能比大小

横排 6.2:1、竖排 0.65:1，面板是 1.0:1。**竖排更近**，但 `0.65 < 6.2`，写「谁大选另一个」会选错。

**正解**：对数距离 `|ln(比例/目标)|` 取小者（比例是对称的，2:1 与 1:2 一样偏）。

### 6. `state` 字段要显式带进数据

我第一版忘emit，导致数值查看器读不到值、静默不渲染。L00 的 trace 里 `state` 是**每步都有**的（步 4 有 `acc`）。

### 7. 一屏的关键取舍：**只留 DAG + 公式侧栏**

原来四个面板（DAG + 张量网格 + 公式 + 时间轴）同屏塞不进一屏。示例页的做法是：
- 左/上：DAG
- 右/下：公式侧栏（含 读/写 chips、数值块、narration）
- 底：控制条吸底

实测 PC `900/900`、手机 `844/844`，**零滚动**，且手机是真适配（不是降级）。

## 数据侧要改什么

**trace 不用变**。`tensors` + `steps[].reads/writes/state` 已经够推导出「变量为节点、计算为边」的图 ——
示例页就是从现有 trace 现推的，没有任何新字段。

唯一要补的是 **`binding.sym` → 变量名**的映射（哪几个张量出现在这条公式里）。
示例页用正则从 `sym` 里提取（`\mathrm{acc}^{(j-1)}` → `acc`），可行但要小心词边界
（`x` 不能命中 `x_blk` 内部）。**更好的做法是让生成器直接输出这个映射**，别在页面里猜。
